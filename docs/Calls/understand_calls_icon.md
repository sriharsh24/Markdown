# Understand the Calls Icons

The Calls screen contains several icons, buttons, and elements that help you manage calls. Understanding each element helps you use WhatsApp Calls effectively and access features quickly.

## Call Icons

| Icon | Description |
|---|---|
| Call Icon | Tap to make a new voice or video call instantly. |
| Schedule Icon | Tap to create a scheduled call with a date and time. |
| Keypad Icon | Tap to enter a phone number without selecting contacts. |
| Favourites | Tap to view and manage your favorite contacts. |
| Voice Call Icon | Tap to start a voice call with the selected contact. |
| Video Call Icon | Tap to start a video call with the selected contact. |
| Info Icon | Tap to see all past calls with a specific contact. |

## Call Indicators and Status

| Indicator | Description |
|---|---|
| Outgoing | You initiated the call. |
| Incoming | You received the call. |
| Missed | You did not answer the call. |
| Call Duration | Shows how long the call lasted. |
| Call Date/Time | Shows when the call occurred. |
| Voice Call | Indicates a voice-only call. |
| Video Call | Indicates a video call. |
